# 시작 화면·로그인 디자인 복원 안내

2026-10-23 사용자가 승인한 현재 디자인을 메인 브랜치에 다시 적용하기 위한 백업입니다.

## 범위

시작 화면과 로그인 화면만 복원합니다. App.reference.tsx 전체를 메인 App.tsx에 덮어쓰지 마세요. 참고 파일에는 다른 피처의 라우팅과 세션 코드가 포함되어 있습니다. 메인의 인증, 권한, 라우팅, 부서 업무, 사진 첨부 기능을 기준으로 디자인 부분만 통합하세요.

## 최종 디자인

- 시작 배경: 위 파랑 #4b97db → 중간 #51aebf → 아래 민트 #59cba5 그라데이션.
- 시작 로고: assets/skope-splash-clean.svg. 청록색 원과 매끈한 흰 고양이·타깃 선. 다른 생성 이미지로 교체하지 않습니다.
- 왼쪽에서 회전하며 중앙으로 굴러온 뒤 살짝 점프합니다(1.55초).
- 시작 후 2초에 전환을 시작하고 0.7초 동안 페이드아웃합니다.
- 전환 시 시작 로고가 로그인 화면 왼쪽 위 로고 중심으로 이동하며 축소됩니다. Splash의 getBoundingClientRect/animate 로직을 보존합니다.
- 시작 문구: 서경대학교 캠퍼스 문제 신고 서비스. 크기 clamp(22px,3vw,34px).
- 한글 Pretendard, 영문 Nunito. assets/fonts에 로컬 글꼴과 라이선스가 있습니다.
- 로그인 왼쪽 위 로고: assets/skope-symbol.png. 흰 사각 배경 없이 초록 원만 표시.
- 로그인 제목: 문의부터 처리 결과 확인까지, SKOPE.
- 로그인 부제: 서경대학교 캠퍼스 문제 신고 서비스.
- 로그인 화면의 ‘시연 서비스 · 실제 학교로 전송되지 않아요’ 배너는 삭제된 상태를 유지합니다.
- 캐릭터: assets/skot-mascot.png. 원래 비율 유지, 너비 calc(320px + 1cm), 최대 100%. 발이 로그인 박스에 붙도록 bottom:calc(100% - 12px).
- 로그인 박스: 둥근 흰 카드와 은은한 그림자. 민트 배경, 기존 연두 로그인 버튼 유지.
- 로그인 폼의 실제 계정 인증 동작은 메인 코드를 보존합니다.
- 로그인 이후 화면에는 이 백업의 디자인을 적용하지 않습니다.

## 적용 순서

1. assets의 이미지와 fonts를 메인의 frontend/public 아래에 복사합니다.
2. login.css를 frontend/src/login.css로 복사하고 App에서 import합니다.
3. App.reference.tsx의 Login, Splash, Mascot 컴포넌트 디자인을 참고해 메인에 통합합니다. 기존 submit/세션·권한 처리를 유지합니다.
4. App의 intro 상태와 2000/2700ms 타이머, 로딩 중 Splash, 로그인과 Splash를 함께 렌더링하는 분기를 통합합니다. useEffect/useRef/useState가 필요합니다.
5. 모션 감소 설정 대응을 보존합니다.
6. 프런트 빌드 및 메인에 존재하는 인증/권한 회귀 테스트를 확인합니다.

이 백업은 앞서 추가한 사진 첨부 UI나 로그인 이후의 디자인 변경을 복원하기 위한 것이 아닙니다.
