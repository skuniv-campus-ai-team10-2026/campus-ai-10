SKOPE 현재 구현 화면 — 디자이너 전달용
2026-10-18

압축 해제 후 index.html을 열면 화면별 설명과 이미지를 함께 볼 수 있습니다.
JPG 파일 15장은 메신저에 개별 첨부하거나 Figma 참고 이미지로 사용할 수 있습니다.

현재 임시 프론트엔드의 실제 실행 화면이며 최종 디자인 시안이 아닙니다.
모양·색상·배치를 그대로 유지할 필요는 없습니다. 앞서 전달한 디자인 요청 내용과 함께 보세요.
DEMO 분석, RULE_ONLY 유사 후보, 분리된 H2 메모리 DB로 캡처했습니다.
유료 AI 호출 0회. 기존 MySQL 개발·시연 데이터는 수정하지 않았습니다.
실제 개인정보, API 키, 비밀번호는 포함하지 않았습니다.
누수 담당 부서는 시연용 가정 배정입니다. 실제 학교 전송이나 현장 조치를 뜻하지 않습니다.
직접 입력 화면은 선택 경로이며 학생 전체가 거치는 필수 확인 단계가 아닙니다.
로딩·오류 전체 상태, 모바일·PWA 화면, 아직 통합되지 않은 사진 첨부 기능은 포함하지 않았습니다.
