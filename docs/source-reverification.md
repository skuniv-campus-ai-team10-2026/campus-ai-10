# 공식 담당 부서·행정 절차 재확인

확인일: **2026-10-11 KST**. `docs/data-sources.md`와 남은 검증 항목을 읽은 뒤 서경대학교 `skuniv.ac.kr` 공식 도메인의 검색 결과 및 실제 페이지 본문을 조회했다. 아래의 게시일과 자료 기준일은 확인일과 다르다. 연락처로 전화하거나 이메일을 보내지 않았으며, 학교 시스템에 로그인·민원 접수·외부 데이터 수정은 하지 않았다. 이 작업은 코드나 시드를 변경하지 않은 근거 조사다.

## 판정과 최소 적용 제안

| 대상 | 이번에 확인한 것 | 미확인·제한 | 최소 제안 |
|---|---|---|---|
| 누수 → 건설관리과 | 공식 사무분장규정상 건물 시설·영선 관리 담당. 공식 공지에서 저수조 청소/단수 문의 `02-940-7028` 확인 | 누수 신고의 직접 접수 전화, 설비실 직통번호, 장소별 담당 배정은 미확인 | 현행 `FACILITY/LEAK` 비활성·관리자 확인 유지. 시설관리 부서라는 사실과 누수 전담 연락처 확인을 동일시하지 않음 |

| 일반 휴·복학 절차 | 상시 안내 페이지와 2026-2학기 상세 공지에서 절차 확인 | 공지의 접수기간은 종료됨. 미래 학기 일정·현재 예외접수 가능 여부는 미확인 | 출처·대상·기준학기·유효기간을 포함한 제한된 안내 데이터로 구현 가능. 일반 문의처 RoutingRule만으로 자유 절차 답변을 활성화하지 않음 |
| 무전공 학생 휴·복학 | 2026-2학기 별도 대상과 대면/서류 제출 절차 확인 | 일반 재학생 절차와 다름 | 대상 확인 없이 일반 포털 절차를 단정하지 않음. 해당 공지로 안내하거나 추가 질문 필요 |

`verified=true`를 어느 사실에 적용하는지 구분해야 한다. 부서의 존재·일반 업무·특정 전화의 특정 업무·현재 접수 가능 여부는 서로 다른 주장이다. 현 스키마가 이를 하나의 플래그로 표현하므로 근거가 부족한 누수 자동 배정까지 활성화하지 않는 것이 현재 계약과 일치한다.

## 누수·시설 관리 근거

### S1. 현재 공식 규정집 목록 및 사무분장규정

- [대학규정집 목록](https://www.skuniv.ac.kr/rules): 실제 본문에는 자료 1건, 표시 연도 2025, 제목 `2024 제15회 서경대학교 규정집`이 있었다. 일자 수준 게시일은 페이지에서 확인되지 않았다.
- 목록의 PDF 다운로드를 따라 [공식 규정집 PDF](https://www.skuniv.ac.kr/wp-content/uploads/2025/11/b0a2c919-111b-4c0b-bcc2-ffc4b8bf4cb0.pdf)를 열었다. 편찬례에는 **2024-09-01 기준**이라고 명시되어 있다. URL의 `2025/11`을 규정 최신 시행일로 해석하지 않았다.
- 사무분장규정 제23조, PDF 물리적 **230쪽**(0 기준 229), 인쇄면 **112쪽**: 건설관리과가 건물 시설과 영선을 관리하고 공사 발주·시공·감독·검사를 맡는다는 업무 범위를 확인했다. 같은 조에 전기·에너지, 연구실 안전 등의 업무도 있다.
- 판정: 시설 관리 담당 부서의 근거는 확보했다. 이 조항에 누수 신고 전화 또는 설비실 번호는 없으므로 특정 누수 전화로 확대 해석하지 않는다. 본문 추출을 읽었으며 PDF 이미지 렌더링 요청은 도구의 cache miss로 실패했다.

### S2. 저수조 청소에 따른 단수 안내

- [공식 공지 본문](https://www.skuniv.ac.kr/notice/54086)
- 작성자 총무처, 게시일 **2025-06-11**.
- 교내 건물 저수조 청소로 인한 단수 일정 안내에서 건설관리과 `02-940-7028`을 문의처로 명시했다.
- 판정: 기존 기록의 “7028은 연구실 안전에서만 확인”보다 근거 범위가 넓어졌다. 그러나 저수조 청소 문의가 누수 전담 신고 번호라는 직접 증거는 아니다. 해당 단수 일정은 과거 정보다.

### S3. 2026년 신규 연구활동종사자 연구실 안전교육 안내

- [공식 공지 본문](https://www.skuniv.ac.kr/notice/63618)
- 작성자 건설관리과, 게시일 **2026-04-21**.
- 실제 읽은 교육 안내 본문의 문의처가 총무처 건설관리과 `940-7028`이다. 지역번호까지 포함한 표기는 S2 본문에서 확인했다.
- 보조 검색에서 [2026-04-07 특수건강검진 공지](https://www.skuniv.ac.kr/notice/63145)의 `02-940-7028` 표기가 나왔으나, 해당 URL의 별도 본문 열기는 cache miss로 실패했다. 이 보조 결과를 본문 접근 성공으로 세지 않았다.
- 판정: 2026년에도 해당 부서 연락처가 공식 공지에 사용됐음을 확인했다. 이번 조회만으로 현재 통화 연결·누수 접수 범위를 검증한 것은 아니다.

### S4. 조직도·전화번호의 접근 범위

- [공식 조직도·전화번호](https://www.skuniv.ac.kr/organization-phone), 게시·수정일 표시는 확인되지 않았다.
- 공식 검색 결과에는 총무처 아래 건설관리과가 표시되지만, 페이지 본문 읽기 결과에서는 동적 부서 상세 연락처가 빠졌다. 브라우저 도구는 `Browser is not available: iab`, 브라우저 목록은 빈 배열을 반환했다. 로컬 HTTP 조회도 DNS 해석에 실패했다.
- 따라서 **건설관리과 팝업이나 설비실 전화번호를 직접 읽었다고 보고하지 않는다.** 현재 공식 연락처에서 “설비실”을 누수 직통 창구로 확인하지 못했다. 학교 대표 번호 또는 상황실 번호를 누수 담당 번호로 임의 대체하지 않았다.

## 휴학·복학의 공식 근거

### S5. 상시 휴학·복학 안내

- [휴학·복학](https://www.skuniv.ac.kr/leave-and-return), 게시·수정일 표시는 확인되지 않았다.
- 일반적인 휴학은 인터넷 신청 및 학과 승인 흐름으로 안내한다. 군입대 휴학에는 관련 서류를 갖춘 교무과 방문 절차가 있다. 복학은 인터넷 접수와 교무과 처리로 설명하며, 제대복학은 서류를 `service@skuniv.ac.kr`로 제출하도록 안내한다.
- 판정: “휴·복학 절차 근거 자체가 없다”는 이전 기록은 갱신할 수 있다. 다만 학생 유형·신청 종류·해당 학기 상세 공지를 함께 확인해야 하며 현재 신청 가능 여부를 이 페이지 하나로 단정하지 않는다.

### S6. 2026학년도 2학기 휴학 및 복학 신청 안내

- [일반 대상 상세 공지](https://www.skuniv.ac.kr/notice/65414)
- 작성자 교무처, 게시일 **2026-07-14**, 페이지 상태 `진행완료`.
- 대상에서 미래융합1·2 및 자유전공 학부생을 별도 공지로 구분한다. 일반 휴학·재휴학과 일반복학은 서경포탈의 학부학사/학적관리/학적변동관리에서 각각 해당 신청 메뉴로 진행하도록 설명한다. 휴학 전 학과장 상담을 안내하고 군입대·제대복학 등에는 별도 서류 절차를 둔다.
- 문의처는 교무처 교무과 **02-940-7068, 7071, 7020**. 공지의 신청기간 **2026-07-20~2026-08-28**은 확인일 현재 종료됐다.
- 판정: 문의처 및 해당 학기·대상 절차는 확인됐다. 현재 가능한 신청이나 2027학기 신청기간으로 재사용하면 안 된다.

### S7. 2026학년도 2학기 무전공 신입생 휴학 및 복학 신청 안내

- [무전공 대상 상세 공지](https://www.skuniv.ac.kr/notice/65413)
- 작성자 FYP센터, 게시일 **2026-07-14**.
- 대상은 미래융합학부1·2 및 자유전공학부의 26학번 신입생과 전공 배정을 받지 않은 25학번 휴학생이다. 해당 대상의 휴학은 FYP디렉터 면담과 확인을 포함한 대면 서류 제출을 요구한다. 복학에도 신청서의 방문/이메일 제출 안내가 있다.
- 휴·복학 문의는 교무처 교무과 **02-940-7068**. 전공 배정·학교생활 문의인 FYP센터 **02-940-7693 / 7020 / 7074**와 업무가 구분된다.
- 판정: 일반 대상 온라인 절차를 모든 학생에게 적용하는 답변은 잘못될 수 있다. `7020`이 다른 업무 문의에도 표기되므로 전화번호 하나로 업무 범위를 역추론하지 않는다.

## 상충·불확실성 처리

1. **적용 대상 차이:** 일반 대상 공지의 포털 신청과 무전공 대상 공지의 대면 신청은 대상이 다른 안내다. 이를 하나의 절차로 합치지 않는다.
2. **일정 차이:** [학부 학사일정](https://www.skuniv.ac.kr/academic-calendar)의 공식 검색 결과에는 2학기 학적 신청이 7월 20~31일로 잡혀 있었다. 실제 페이지 본문에서는 동적 일정 상세를 읽지 못했으므로 이 일정은 본문 재검증이 안 된 교차 확인 항목이다. S6의 실제 본문은 8월 28일까지라고 안내한다. 캘린더만 보고 더 짧은 마감을 정답으로 반환하지 않는다.
3. **상시 안내와 학기 공지:** 상시 안내의 제대복학 서류 예시와 학기 공지의 서류 명시가 완전히 같지 않다. 특정 학생의 제출 서류를 단정하는 기능은 해당 학기 공지와 학생 유형을 확인해야 한다.
4. **최신성의 한계:** 공식 웹 조회 결과는 공개 자료의 존재와 내용을 확인한 것이다. 담당자 실시간 통화, 비공개 내부 배정, 2026-10-11 이후 변경 또는 예외 접수 여부는 검증하지 않았다.

## 구현 담당자에게 전달할 변경 후보

- **바로 갱신 가능한 조사 기록:** 교무과 휴·복학 문의처의 2026 공식 근거와 S5~S7 링크를 데이터 출처 문서에 추가. `verifiedAt`은 실제 확인일을 쓰고 게시일·기준학기는 별도로 기록한다.
- **안내 데이터 구현 시 필요한 최소 조건:** `topic`, `audience`, `sourceUrl`, `publishedAt`, `verifiedAt`, `effectiveFrom/effectiveUntil` 또는 “기간 확인 필요” 상태를 함께 보존한다. 질문 대상이 불명확하면 학생 유형을 먼저 묻거나 공식 안내 링크만 제공한다. 현재 날짜가 공지 기간 밖이면 기간 종료를 표시한다.
- **활성화하면 안 되는 추정:** `LEAK → 설비실 특정 전화`, 모든 학생의 포털 휴학, 2026-2학기 신청기간을 현재 진행 중으로 표시, 특정 연락처를 모든 학적·시설 업무의 전용 창구로 설명하는 것.

이번 조사에서 파일 변경은 이 문서 하나뿐이며, 기존 시드·라우팅 활성 상태·DB·앱 답변 로직은 변경하지 않았다.
