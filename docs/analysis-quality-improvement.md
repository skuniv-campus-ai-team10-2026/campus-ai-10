## 새로 발견된 층 표기 회귀와 정규화

S25 입력은 `한빛관 승강기가 1층에서 문을 열지 않습니다.`이다. 이전 LIVE는 `floor="1"`이었지만 새 프롬프트 LIVE는 `floor="1층"`을 반환했다. 의도 REPORT, OTHER/UNKNOWN, 건물 한빛관 등 나머지 평가 필드는 정답이었다. 층 자체의 의미는 같아도 서버 계약의 정규 형식에 맞지 않아 **회귀 FAIL**로 기록했다.

- `1층`, `1 층`, `1` → `1`; `지하 1층`, `b1`, `B1층` → `B1`.
- 양수 1~999 범위의 명확한 숫자 층만 처리한다. `null`은 그대로 유지한다.
- 범위·자유 문장·호실·불명확한 값은 변환하지 않는다. 예: `1~2층`, `1층 또는 2층`, `101호`, `본관 1층`, `옥상`, `0층`, `-1층`, `01층`.
