| S25 승강기가 1층에서 문을 열지 않음 | 기존에는 PASS | 이번 응답의 `floor`가 `1` 대신 `1층` | **새 FAIL**: 층 의미는 같지만 요구한 표준 문자열 불일치 |

기존 실패 4건이 모두 개선됐고, 기존 성공 26건 중 25건을 유지했다. 새 회귀 1건 때문에 전체 필드 일치는 **86.7% → 96.7%**다. S25 정답을 `1층`으로 바꾸거나 이 결과를 30/30 성공으로 보고하지 않는다. 현재 실제 측정에서 층 필드는 29/30이고, intent/category/subcategory/building/emergencyHint는 각각 30/30이다. 장소·증상 존재 검사에는 해당 필드가 필수가 아닌 문장의 자동 통과가 포함되므로 30/30을 모든 자유문장 의미 정확도로 해석하지 않는다.

S25에는 추가 추론 없이 운영 코드의 `AiService.normalizeFloor`를 적용했다. 이 함수는 `1층`을 `1`, `지하 1층`·`b1` 등을 `B1`로 정리하며 범위·호실·불명확한 문장에서는 층을 추측하지 않는다. 저장한 30개 LIVE 출력에 이 함수를 적용한 별도 재생에서 **변경된 출력은 S25 한 건뿐**, 전체 필드 일치는 **30/30**이었다. 기존 캐시·LIVE 파일은 전후 SHA 검사를 통과했고, 재생 도구는 실제 공급자 호출을 허용하지 않는다. 따라서 원본 실제 재측정의 29/30과 새 회귀 기록도 그대로 유지한다.

이번 품질 평가 실제 응답 사용량은 LLM 입력 **24,888**, 출력 **2,582** 토큰, Embedding 입력 **1,473** 토큰이다. 캐시 적중과 OFFLINE 재생은 신규 API 사용량에 더하지 않았다. 브라우저 E2E의 추가 호출은 이 51회 평가와 별도로 집계한다. 계정의 실제 결제 명세는 확인하지 않았다. API 키나 실제 학생 개인정보는 이 결과 파일에 포함하지 않았다.

재현 명령은 `scripts/Test-AiQualityReplay.ps1`이며 `scripts/Test-AiQuality.ps1 -Mode OFFLINE`도 이 경로로 위임한다. 환경 키 파일을 읽지 않으며, 저장 출력의 층 정규화와 저장 벡터의 최종 후보 정책만 재실행한다. 새 프롬프트의 재검증을 원하는 경우와 구분해야 한다.
