# PR #4 관리자 화면 디자인 수정 검증 (2026-10-26)

- 신고 목록: 처리 상태·배정 상태·이관 요청 필터를 한 줄 필터 바로 정리했다. 처리 상태는 탭 대신 선택 상자로 고르며, 선택 시 기존 탭과 같은 `status` 조건으로 조회한다.
- 신고 상세(관리자): 문의는 "문의 접수"·"답변"·"답변 (필수)"·"답변 저장하고 처리 완료"·"답변이 완료된 문의입니다." 문구를 사용한다. 문의에서 값이 없는 발생 장소·건물/층·발생 시점·발생일 칸은 숨기고, 일반 신고는 기존처럼 미확인 값도 표시한다.
- 신고 상세·사건 상세의 검토 이력에서 `CREATED`, `INCIDENT_LINK`, `SIMILARITY_REVIEW`, `RECURRENCE_REVIEW`, `ROUTING_CHANGED`, `TRANSFER_REQUESTED`를 한국어 이름으로 표시한다.
- 유사 신고 후보 이유는 백엔드 문장을 그대로 두고 문장 단위 목록으로 표시한다. 카드마다 반복되던 RULE ONLY 배지는 제목 옆 배지 하나로 정리했다.
- 사건 상세: 재발 검토 이력은 "과거 사건 #N과 비교" 링크와 "자세히" 펼치기로 표시하며, 원문 내용은 펼친 영역에 모두 남긴다. 이미 저장한 재발 판단과 같은 버튼은 비활성화해 같은 판단이 중복 기록되지 않게 했다. 이전 사건 번호를 바꾸면 다시 저장할 수 있다.
- 영어 보조 라벨(eyebrow)을 관리자 화면과 학생 홈에서 제거했고, 글자 크기·줄바꿈을 PC/모바일별로 정리했다.
- 학생 화면은 홈의 영어 라벨 제거 외에는 변경하지 않았다. 백엔드 코드·API는 변경하지 않았다.
